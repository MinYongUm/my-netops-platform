설계에 없던 결정을 시간 순으로 기록한다. 형식: 날짜 | 결정 | 이유

- 2026-11-01 | 커밋 승인 시 Claude Code가 push까지 진행 | 승인 한 번으로 끝내기 위해. 허용 push는 git push, git push origin main만
- 2026-11-01 | 커밋 전 reviewer 서브에이전트 리뷰 | 이 방과 Claude Code 간 수동 전달을 줄이기 위해
- 2026-11-01 | zabbix_api.py 로거는 getLogger(__name__) | bootstrap 외 스크립트도 공용으로 쓰므로. 출력 형식에 이름이 없어 화면 출력은 같다
- 2026-11-01 | 프로필 중복 키는 yaml.compose(SafeLoader) 노드 트리로 검사하고 값은 yaml.safe_load로 읽는다 | safe_load는 중복 키를 덮어쓴다. compose는 객체를 만들지 않아 안전하고 safe_load만 쓰는 규칙을 지킨다
- 2026-11-01 | 프로필의 sites와 devices가 빈 목록이면 오류 | 실수로 비우면 Sites/*의 모든 호스트가 비활성되기 때문
- 2026-11-01 | 프로필의 모든 문자열 값은 앞뒤 공백이 있으면 오류 | 따옴표 안 공백 때문에 보이지 않는 차이로 다른 이름·그룹이 만들어지지 않게
- 2026-11-01 | code와 name 중복은 대소문자 무시하고 검사 | SEL과 sel 같은 경우 사람이 같은 것으로 착각하기 쉽고 관리 대상이 헷갈리기 때문
- 2026-11-01 | 프로필에서 앵커(&), 별칭(*), merge key(<<)는 모두 오류 | merge key는 직접 쓴 키를 조용히 덮어써 중복 키 검사를 피한다. 파일에 보이는 그대로 적용되게 하기 위해
- 2026-11-01 | code도 name과 같이 영문·숫자·. - _ 만 허용 ('/' 금지를 포함) | 공백·탭·제어문자가 그룹 이름 Sites/<code>에 들어가지 않게
- 2026-11-01 | ip에 0.0.0.0, 255.255.255.255, loopback(127/8), multicast(224/4)는 오류. 공인 IP는 허용 | 장비 주소가 될 수 없는 값. 공인 IP는 회사망에서 쓸 수 있다
- 2026-11-01 | inventory.py 프로필 검사는 오류를 끝까지 모아 전부 출력하고 종료 코드 1 | 여러 번 고쳐 다시 돌리지 않게
- 2026-11-01 | inventory.py CLI는 위치 인자 profile 하나로 시작. --dry-run, --env-file은 조회 단계에서 추가 | 한 번에 하나씩
- 2026-11-01 | ip에 예약 대역(240.0.0.0/4, is_reserved)과 link-local(169.254.0.0/16, is_link_local)도 오류 | 둘 다 장비 관리 주소가 될 수 없다. 255.255.255.255는 is_reserved에 포함된다
