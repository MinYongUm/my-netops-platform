# Lesson 0-1: 저장소 초기화 + compose.yaml 수동 구성

## Goal

- compose.yaml에 PostgreSQL → Zabbix Server → Zabbix Web → Grafana를 한 서비스씩 추가하여 기동
- 완료 기준: 4개 컨테이너 정상 기동 / Grafana에서 Zabbix 데이터 조회 / down -v 후 up 재기동 동일 / 비밀번호는 .env 분리

## Environment

- Host: Proxmox VE 9.1.1, VM ldevu01 (공용 개발서버), user netadmin (docker 그룹)
- OS: Ubuntu 24.04.5 LTS
- Docker 29.9.0, Docker Compose v5.6.0 (CLI plugin)
- 8080은 open-webui 사용 중 → Zabbix Web 호스트 포트는 ZBX_WEB_PORT로 분리
